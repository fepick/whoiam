# v0.04 배포 준비 점검

점검일: 2026-11-04. 배포 형태는 다른 Windows PC에서 실행하는 **로컬 설치용 소스 ZIP**입니다.
실제 정보가 들어 있는 보관함·운영 DB·OS 자격증명은 개발 도구로 열지 않았습니다.

## 1. 표시와 문서

- 보고 PNG의 워터마크는 `업무비서 whoiam` / `버전 0.04 · powered by codex`입니다.
- 현재 소스와 공개 문서의 워터마크에서 사용자 이름을 제거했습니다.
- README의 화면은 메모리 데모에서만 촬영했습니다. 사용자가 입력한 실제 업무나 보관함을 촬영하지 않았습니다.
- [설치 가이드](setup.md)에 수동 설치·설치 스크립트·CLI AI에 붙여 넣을 요청문을 제공합니다.

## 2. Git 개인정보·민감정보 점검

원격 브랜치를 갱신한 뒤 현재 파일과 모든 로컬·원격 참조에서 도달 가능한 Git 객체를 검사했습니다.
금지 경로 검사, 알려진 공급자 토큰·개인키·JWT 패턴 검사, 이메일·비밀번호 리터럴 후보의 가상 데이터 여부 검토를 수행했습니다. 값 자체는 검사 로그에 출력하지 않았습니다.

| 항목 | 결과 |
| --- | --- |
| 금지된 데이터·키·운영 DB·증빙·세션 경로 | 현재 및 Git 이력에서 발견하지 못함 |
| 알려진 공급자 토큰·개인키·JWT 패턴 | 발견하지 못함 |
| 이메일·비밀번호 리터럴 후보 | 테스트용 `example.invalid` 주소와 가상 문자열로 확인 |
| 사용자 이름 | 현재 파일과 관리 대상 브랜치·태그 이력에서 제거. 이전 PR 참조·캐시는 별도 확인 대상 |
| Git 작성자 메타데이터 | 관리 대상 이력의 개인 작성자·커미터 주소를 공개 별칭과 GitHub noreply 주소로 치환 |
| 이전 목업 연결 설정 | Git에는 프로젝트 식별 설정이 있으나 토큰 필드는 없음. 배포 ZIP에서는 제외 |

이 검사는 임의의 형태로 숨겨진 모든 비밀값이 없다는 보증이 아닙니다. 운영 저장소는 검사 대상에서 제외했습니다.
2026-11-04에 암호화 Git 백업을 만든 뒤 `git-filter-repo`로 관리 대상 전체 이력을 정리했습니다.
15개 브랜치와 태그 집합을 보존했고, 최신 배포 소스 트리가 정리 전과 동일함을 확인했습니다. 원래 이름·이메일을 대상으로 검사한 Git 객체의 잔존 일치는 0건입니다.
이 검증 범위는 갱신한 브랜치·태그입니다. **기존 PR의 GitHub 읽기 전용 참조·캐시와 제3자의 clone·fork까지 삭제되었다는 뜻은 아닙니다.**
GitHub 지원에 의한 추가 정리는 지원 기준에 따라 달라지며, 필요한 확인 절차는 [이력 정리 안내](history-cleanup.md)에 설명합니다.
GitHub 저장소 공개 전환은 수행하지 않습니다.

## 3. 배포 파일 구성

```powershell
.\.venv\Scripts\python.exe scripts/build_release.py
```

커밋된 HEAD에서 실행 소스·정적 파일·설치/운영 스크립트·문서·의존성 목록만 명시적으로 골라 `.tmp/releases/whoiam-0.04.zip`을 만듭니다.
`.git`, `.private`, `.env`, 운영 DB, 키, 증빙, 개발 가상환경, 이전 목업 배포 설정은 포함하지 않습니다. 심볼릭 링크도 거부합니다.
파일별 SHA-256과 원본 커밋을 `MANIFEST.json`에 넣습니다. 기존 ZIP은 덮어쓰지 않습니다.
Python 실행 파일과 의존성 wheel은 ZIP에 포함하지 않으므로 대상 PC에 Python 3.11 이상과 의존성 설치 경로가 필요합니다.

## 4. 검증

- 전체 Python 테스트: 71개 통과. 운영 OS 자격증명은 사용하지 않는 가상 테스트입니다.
- 웹 회귀 테스트: 15개 통과. 필수 black·isort 검사와 민감 경로 검사도 통과했습니다.
- 고정된 실행 의존성 29개 wheel 다운로드 가능 여부 확인.
- ZIP만 별도 폴더에 풀어 새 가상환경을 만들고 설치 스크립트·`pip check`·메모리 데모의 API/정적 화면 정상 응답을 확인했습니다. 데모 서버는 정상 종료했습니다.
- 패키지 66개 파일의 SHA-256을 `MANIFEST.json`과 대조했습니다. 실제 다른 물리 PC에서의 검증은 수행하지 않았습니다.
- 지원 범위는 Windows 계정별 개인용 루프백 실행입니다. 외부 서버·다중 사용자 배포는 검증하지 않았습니다.

## 5. 브랜치 통합

확인한 모든 기존 작업 브랜치의 변경은 최신 작업 이력에 이미 포함되어 있습니다. `release/v0.04`가 전체 기능과 배포 준비 변경을 모읍니다.
불필요한 병합 커밋이나 기존 브랜치 삭제 없이 이 통합 브랜치를 검증합니다.
`main` 반영은 [AGENTS.md](../AGENTS.md)의 “프로젝트 담당자가 함께 있으면서 내용을 직접 확인한 경우에만 허용” 규칙에 따라 최종 검토 후 진행합니다.
공개 릴리스·GitHub 공개 전환·실제 데이터 이전은 수행하지 않습니다.
