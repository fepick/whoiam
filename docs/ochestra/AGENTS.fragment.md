# Ochestra 공통 지침 연결

작업 전 `docs/ochestra/common.md`를 읽고 적용한다. 작업에 지정된 역할은 `docs/ochestra/agents/`에서 읽는다. 기존 프로젝트 지침과 충돌하면 충돌 내용을 보고하고 프로젝트 요구사항을 우선 확인한다.

전문 역할: circuit-design, bom, schematic-wiring (KiCad MCP 필수), report-writer, deliverables, brand-philosophy.
보조 역할: coordinator, repository-setup, verification.
역할별 입력과 출력은 `docs/ochestra/task-brief.md` 형식으로 전달한다.
