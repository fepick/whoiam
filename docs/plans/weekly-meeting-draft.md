# 주간 미팅 발표자료 초안 — 계획 (미구현)

사용자가 시작일·종료일을 선택하면 해당 기간의 업무 진행·완료 기록을 요약한 발표자료 초안을 만든다. 이번 변경에서는 구현하지 않는다.

## 범위와 화면

- 기록 / 보고에서 시작일·종료일을 지정한다. 기본값은 이번 주 월요일부터 오늘까지이며 한국 시간 기준 양끝 날짜를 포함한다.
- 주요 성과, 완료 업무, 진행 중 업무, 기록에 명시된 문제·확인사항, 다음 행동 순서로 초안을 구성한다.
- 업무별 날짜·원본 로그 참조를 유지하고 사용자가 초안을 수정·저장한다. 기록이 없으면 빈 기간임을 알린다.
- 초기 출력은 발표용 제목과 항목으로 구성된 텍스트 초안이다. 슬라이드 파일 출력과 외부 공유는 후속 범위다.

## 구현 순서

1. 업무 모듈에 기간 조회 기능을 추가한다. 보고 모듈은 공개 조회만 사용한다.
2. 기간 내 로그를 업무별로 묶고 합산·중복 제거·날짜 검증은 코드로 처리한다. 현재 상태로 과거 완료 여부를 추정하지 않는다.
3. 우선순위·진행도는 기록 당시 값을 이용한다. 완료 후 재개도 날짜순으로 설명한다. 과거 값이 없으면 미기록으로 표시한다.
4. AI는 기록에 근거한 요약과 문장 생성을 보조한다. 기록 없는 성과·문제·계획은 만들지 않는다. 규칙 기반 초안도 고려한다.
5. 검토 후 명시적으로 암호화 저장하고 원본은 보존한다. 외부 AI 사용 여부·가명화·전송 범위·권한은 구현 전에 결정한다.

## 검증 기준

가상 데이터로 기간 양끝, 월·연도 경계, 잘못된 기간, 빈 기록, 여러 로그 합계, 완료 후 재개, 누락된 과거 진행도, 긴 기록, 원본 추적과 편집 저장을 검증한다. 기간 밖 기록이 섞이지 않아야 한다.
