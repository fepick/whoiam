# 주간 미팅 발표자료 초안

기록 / 보고 → 주간 미팅에서 기간을 선택하면 업무 진행·완료 기록을 발표용 텍스트로 정리합니다. 기본 기간은 한국 시간 기준 이번 주 월요일부터 오늘까지입니다. 조회에는 시작일과 종료일이 모두 포함됩니다.

## 생성과 저장

- 업무별 소요시간을 합산하고 기간 내 마지막 로그의 상태, 우선순위, 진행도를 표시합니다. 완료 후 재개는 날짜순 상태 이력에 표시합니다. 과거 값이 비어 있으면 미기록으로 표시합니다.
- 주요 성과, 완료 업무, 진행 중 업무, 문제·확인사항, 다음 행동 순으로 구성합니다. 메모의 `성과:`, `문제:`, `확인사항:`, `다음 행동:`으로 시작하는 줄은 해당 항목에 넣고, 일반 메모는 해당 업무에 표시합니다. 같은 업무에서 같은 날짜에 반복된 메모 문장은 한 번 표시합니다.
- 규칙 기반으로 로컬에서 생성합니다. 원본 업무 로그를 펼치면 날짜, 기록 당시 값, 메모와 로그 ID를 볼 수 있습니다. 로그가 없는 기간에는 화면에 안내를 표시합니다.
- 발표 내용을 수정하고 **발표 초안 저장**을 눌러 텍스트와 원본 참조를 암호화 저장합니다. 저장된 초안을 선택하면 편집한 본문과 연결된 업무 로그를 볼 수 있습니다. 초안을 다시 생성해 저장하면 별도 초안으로 보관합니다.

슬라이드 파일 출력과 외부 공유는 후속 범위입니다.
