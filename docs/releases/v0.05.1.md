# whoiam(후임) v0.05.1

Windows 개인용 로컬 실행 버전입니다. Python 3.11 이상이 필요하며 설치는 [설치 안내](../setup.md)를 따릅니다.

## 변경 사항

- 업무 화면의 기본 보기를 칸반으로 설정하고 보기 버튼을 칸반 → 리스트 순서로 배치합니다.
- 오늘 등록한 업무에 new!를 표시하고, 일일 보고에서도 보고 날짜에 등록한 업무를 강조합니다. 등록 시각이 없는 기존 업무에는 신규 표시를 붙이지 않습니다.
- 일일 진행사항의 우선순위와 진행도를 표시·편집·저장합니다.
- 퇴근 시 작성·저장한 일일 보고를 보존합니다. 초안은 기록 / 보고에서 ‘업무 로그로 초안 생성’을 선택할 때 생성합니다.
- 로컬 VERSION 파일과 GitHub 최신 정식 릴리스를 비교합니다. 운영 프로필은 접속 시와 24시간 간격으로 확인하며 설정 → 업데이트 확인에서 수동 확인할 수 있습니다.
- README·웹 매뉴얼·앱 도움말을 현재 화면에 맞춰 정리했습니다. 주간 미팅 발표 초안과 크롬 구매 도우미의 후속 계획 문서를 포함합니다.

## 업데이트

작성 중인 내용을 저장하고 설정 → 개인 실사용 관리 → 앱 종료로 서버를 종료합니다. 새 설치 ZIP을 별도 폴더에 풀어 설치하거나 Git checkout에서 v0.05.1 태그를 선택한 뒤 의존성을 설치하고 서버를 다시 실행합니다. 기존 미커밋 변경이 있으면 먼저 보존합니다.

운영 데이터는 checkout 밖의 기존 운영 홈을 사용합니다. 이전 코드 폴더의 가상환경을 새 폴더로 복사하지 말고 설치 안내에 따라 준비합니다.

알림은 버전 번호를 비교하므로 새 배포에는 새 버전이 필요합니다. 이번 배포의 VERSION과 태그는 각각 0.05.1, v0.05.1입니다.

## 검증

가상 데이터로 Python·웹 회귀 테스트, 암호화 저장소 경계, 버전 비교·통신 실패·인증, 퇴근 후 보고서 보존을 확인합니다. 필수 포맷 검사와 민감 경로 이력 검사, 배포 ZIP의 파일별 해시 검증을 수행합니다.
