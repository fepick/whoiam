# whoiam(후임) v0.05

개인용 로컬 실행 버전입니다. 기존 실행 서버를 정상 종료하고 업데이트한 뒤 다시 실행합니다.
기존 운영 데이터와 OS 키는 그대로 사용합니다. 설치 방법은 [설치 안내](../setup.md)를 따릅니다.

## 변경 사항

- 로그인 정보·결제수단 참조·개인정보의 일시 조회, 보관함 검색·유형 필터·10건 단위 표시
- 자동 잠금 대기 시간 설정(1~240분, 기본 15분)
- 업무 예상시간·진행도의 마우스 휠 오입력 방지
- 리스트 메모와 보고 PNG 상세의 줄바꿈·점 목록
- 업무 우선순위·예정일 필터, 간결한 칸반 카드와 내용 팝업
- 근무시간 산정 규칙과 기록별 야근 지정
- whoiam(후임) 명칭, 보고 워터마크, 앱 안의 도움말
- 삭제된 릴리스 작업 브랜치 대신 릴리스 태그를 사용하는 설치 안내

## 근무 규칙 적용

설정 → 근무시간 기록 기본설정 → 사내 기준 채우기 → 저장을 누릅니다.
초기는 미적용입니다. 기본값은 08:00 이전, 12:00~13:00, 17:00~17:30 제외입니다.
야근은 기록마다 직접 선택하며 야근 기록에서는 퇴근 준비시간을 인정합니다.
원본 출퇴근 시각을 유지하고 기존 기록의 합계에도 현재 규칙을 적용합니다.
이미 저장한 보고서는 자동 갱신하지 않습니다.

## 검증

가상 데이터로 Python·웹 테스트, 브라우저의 작은 화면·조회·필터·도움말·근무 산정 및 보고 PNG를 확인합니다.
커밋 전 black·isort와 민감 경로 검사를 통과해야 합니다. 실제 운영 데이터나 OS 자격증명은 검증에 사용하지 않습니다.
