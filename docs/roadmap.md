# 구현 순서

v0.03에서 수동 업무 흐름에 개인 실사용을 위한 프로필·키 복구·백업·로그인 자동 실행을 추가했습니다.

| 영역 | 완료한 내용 | 후속 범위 |
| --- | --- | --- |
| 코어 | 모듈 명령·트랜잭션·요청 중복 방지·출퇴근 안내 | 예약 작업·자연어 확장·장치별 인증 |
| 업무 | 계획·상태·날짜별 소요시간·정정·보관 | 프로젝트별 검색·업무 기록 이력 비교 |
| 구매 | 여러 품목 주문·배송 예정·분할 수령·환산 입고·증빙 | 판매처별 자동 구매·배송 조회·반품 |
| 재고 | 품목·원장·실사·BOM 버전·조립 및 추가 손실 | 대체 소자·소수 단위·구매 추천 |
| 근무 | 출퇴근·휴게·정정·주간 합계·급여 차이 대조 | 회사 규칙에 따른 수당·급여 계산 |
| 보고 | 로그 기반 초안·편집 저장·한 장 PNG | 보고 템플릿·제출 연동·이력 비교 |
| 민감정보 | 프로필/UUID OS 키·인증 암호화·잠금·증빙·자동 백업·암호 기반 복구 | 키 교체·외부 연동별 권한 |
| 운영 | checkout 밖의 운영 홈·단일 실행·로그인 작업 설치 도구·앱 종료 | 실제 사용자 재부팅 및 설치 확인 |
| 웹 | 기존 5개 메뉴·입력 화면·작은 화면·기본 110%·운영 설정 | 브라우저 및 실기기 UI 검증 확대 |

개발 과정에서는 실제 운영 저장소와 실제 OS 자격증명을 열지 않았습니다.
가상 데이터로 모듈·로컬 API·암호화·PNG를 검증하며 실제 OS 백엔드는 사용자 환경에서 지원 여부를 검사합니다.
현재 브라우저 자동화 연결이 없어 클릭 기반 UI 검증과 MCU 메모리·성능 검증은 완료하지 않았습니다.

다음 우선순위는 사용하는 판매처와 회사 급여 규칙을 정한 뒤 개별 연동을 추가하고,
OS 키 교체·다중 기기 인증을 구현하는 것입니다. 실제 운영 데이터를 원격 서버로 자동 동기화하지 않습니다.

원격 저장소 연결 시 GitHub 보안 설정과 브랜치 정책을 구성합니다.
초기 실사용 완료 기준은 구매한 물품의 사용 이력을 추적하고, 근무와 업무를 기록하여 일일 보고 초안까지 생성하는 것입니다.
