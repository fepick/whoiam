# 구현 순서

1. 모듈 경계·출퇴근 흐름·민감정보 정책을 문서화합니다. 현재 단계입니다.
   - `apps/web/`에 메뉴 구성과 출퇴근 흐름을 검토할 수 있는 정적 목업을 작성했습니다. 가상 데이터만 사용합니다.
2. 기술 스택·DB·인증·로컬 암호화 및 OS 키 저장 방식을 결정합니다.
3. 민감정보 저장·접근·마스킹·잠금·복원 기능을 구현하고 검증합니다. 이 전에는 실데이터를 사용하지 않습니다.
4. 수동 입력으로 주문→수령→입고, 업무 기록→출퇴근→보고 초안 흐름을 완성합니다.
5. BOM 버전·조립 소모·대체 소자·재고 조정을 구현합니다.
6. 사용하는 판매처부터 배송 조회·증빙 수집을 연결합니다.
7. 자연어 명령과 MCU·서버 연결을 추가합니다.
8. 배포 시 코드만 포함하는 빌드·패키징·산출물 검사를 구현합니다.

원격 저장소 연결 시 GitHub 보안 설정과 브랜치 정책을 구성합니다.
초기 실사용 완료 기준은 구매한 물품의 사용 이력을 추적하고, 근무와 업무를 기록하여 일일 보고 초안까지 생성하는 것입니다.
