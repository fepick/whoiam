# 출근·퇴근 흐름

## 출근

1. 현재 시간과 시간대를 기준으로 근무 세션을 시작합니다. 열린 세션이 있으면 중복 생성하지 않습니다.
2. 이전 미완료 업무와 오늘 일정·마감·우선순위를 조회합니다.
3. 배송 예정·미수집 증빙·입고 대기 등 모듈별 확인 항목을 조회합니다.
4. 오늘 할 일과 주간 누적 근무시간을 안내합니다.

## 퇴근

1. 퇴근 시각부터 기록합니다. 이후 정리 과정이 실패해도 기록은 유지합니다.
2. 출근·휴게 기록을 확인하고 당일·주간 근무시간을 계산합니다. 누락 시 미확정임을 표시합니다.
3. 예정 업무와 실제 업무 로그를 비교합니다. 기록 부재는 미완료가 아닌 확인 필요로 표시합니다.
4. 놓친 업무·증빙·입고·기록 누락을 안내합니다.
5. 사실과 근거에 연결된 일일 보고 초안을 생성합니다. 외부 전송은 별도 명령입니다.
6. 미완료 업무는 다음 근무일 할 일 후보로 연결합니다.

자정을 넘는 근무는 근무 세션 기준으로 처리합니다. 반복 요청은 같은 실행을 중복 반영하지 않습니다.
주간 기준과 휴게·급여 계산은 회사 규칙을 확인한 후 설정합니다. 주 52시간은 사용자가 요청한 추적 기준입니다.

## 민감정보 경계

코어는 민감정보 참조 ID를 전달하며 원문을 해제하지 않습니다.
실제 값은 권한을 확인한 로컬 실행 계층에서 필요한 외부 작업에 한해 사용합니다.
근무·급여·보고 원본도 로컬 운영 데이터이며 GitHub나 배포 파일에 포함하지 않습니다.
AI 보고 입력에는 비밀번호·결제정보·개인식별정보를 넣지 않습니다.
