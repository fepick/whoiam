# whoiam(후임) 웹 콘솔

칸반 카드는 우선순위·분류·제목과 보관/기록/수정/내용 버튼만 표시합니다.
내용 버튼은 메모(줄별 점 목록), 상태, 예정일, 예상 소요시간, 진행도, 오늘 기록 합계를 팝업으로 보여줍니다.
닫기·Esc로 돌아오며 기존 드래그 상태 이동을 유지합니다.

업무 화면의 분류·우선순위·예정일 필터는 리스트와 칸반에 함께 적용됩니다.
예정일은 전체·오늘·이번 주(월~일)·오늘 이전·미정·기간 지정으로 조회합니다.
기간 지정은 시작·종료일을 포함하며 한쪽만 입력할 수도 있습니다. 날짜 조건에는 업무의 예정일을 사용하고,
아래 오늘의 시간 기록·합계도 같은 분류·우선순위·예정일 조건으로 좁힙니다. 잠그면 필터를 초기화합니다.

업무 리스트의 메모와 일일 보고 PNG의 진행·예정 상세내용은 입력한 줄마다 작은 점으로 구분합니다.
빈 줄은 생략하고, 화면 너비에 따른 자동 줄바꿈은 같은 항목으로 이어집니다. 복사용 텍스트 보고는 기존 `-` 양식을 유지합니다.

업무 추가·수정·시간 기록의 예상 소요시간과 진행도는 숫자 키패드를 지원하는 텍스트 입력입니다.
마우스 휠로 값이 바뀌지 않으며, 예상시간 0~525600분·진행도 0~100%를 서버에서도 검사합니다.

홈 / 업무 / 물품 / 기록 / 설정의 5개 메뉴를 사용하는 로컬 업무 앱입니다.
큰 화면은 왼쪽 메뉴, 작은 화면은 하단 메뉴를 사용하며 우측 기기 아이콘으로 작은 화면을 검토할 수 있습니다.
특정 MCU 메모리·성능에서 검증한 펌웨어는 아닙니다.
앱 기본 UI 배율은 110%입니다. 브라우저 배율 100%를 기준으로 하며 사용자 브라우저 설정은 변경하지 않습니다.
메뉴·입력창·대화상자에 함께 적용하고 화면 높이를 보정합니다. PNG의 실제 출력 픽셀 크기는 UI 배율과 분리합니다.

## 실행

프로젝트 루트에서 Python 의존성을 설치한 뒤 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m apps.server --demo=True
```

기본 주소는 http://127.0.0.1:4173 이며 브라우저가 자동으로 열립니다.
데모는 가상 데이터를 메모리에서만 유지하고 서버 종료 시 삭제합니다.
실제 로컬 저장은 데모 옵션 없이 실행하고 서버가 열어준 창에서 잠금을 해제합니다.
이 모드의 키는 프로필별 UUID로 OS 보안 저장소에, 암호문은 기본 `%LOCALAPPDATA%/Whoiam/.private/production/`에 둡니다.
운영·개발·테스트 데이터 홈을 분리합니다. [개인 실사용 안내](../../docs/personal-service.md)를 참고합니다.
개발 도구로 실제 보관함이나 OS 자격증명을 읽지 않습니다.

## 화면 기능

| 메뉴 | 기능 |
| --- | --- |
| 홈 | 출퇴근·휴게, 당일 미완료 업무, 근무 요약, 배송·증빙·부족 재고 확인, 빠른 명령 |
| 업무 | 업무 추가·수정·보관·완료 상태, 우선순위·예정일·예상 소요시간·진행도, 날짜별 소요시간과 정정 |
| 물품 / 구매 | 복수 품목 주문·메모·배송 예정 갱신·분할 수령·포장 단위 입고·증빙 첨부 |
| 물품 / 재고 | 품목·보관 위치·최소 수량, 입출고 원장·실사, BOM 버전·조립 미리보기·일괄 소모 |
| 기록 / 근무 | 실제 출퇴근·휴게·수동 기록·정정, 주간 합계, 월별 예상 실수령액과 입금액 대조 |
| 기록 / 보고 | 실제 업무 로그로 초안 생성·편집 저장·표의 우선순위/예상시간/진행도·한 장 PNG |
| 설정 | 근무 알림 기준·화면 알림, 민감정보 등록·마스킹·잠금, 백업·복원·로그인 자동 실행·앱 종료 |

브라우저 영구 저장소는 사용하지 않습니다. 저장 버튼을 누른 데이터는 로컬 API에서 암호화합니다.
설정 → 보관함 목록에서 로그인 정보의 **보기**를 누르면 ID·비밀번호를 최대 30초 동안 표시합니다. 닫기·화면 이동·다른 창/탭 이동 시 즉시 숨기며, 결제수단·개인정보에는 보기 버튼을 제공하지 않습니다.
입력 후 저장하지 않은 보고서 편집 내용은 새로고침 시 사라집니다.
같은 날짜의 초안 재생성은 수동 편집 내용을 대체하므로 화면에서 확인합니다.
완료 체크만으로 소요시간을 만들지 않으며 시간 기록은 별도로 입력합니다.
업무 화면은 리스트·칸반 보기를 전환할 수 있습니다. 칸반의 예정·진행 중·완료 열 사이로 카드를 드래그하면 상태가 저장됩니다.
칸반 카드는 예정일·예상시간·진행도·오늘 기록 왼쪽 정보와 오른쪽 시간 기록·수정 버튼을 나란히 배치해 높이를 줄입니다.
카드의 **보관**은 확인창 없이 한 번에 보관 상태로 저장하고 기본 보드에서 숨깁니다. 보관 필터에서 확인하고 수정 버튼으로 상태를 되돌릴 수 있으며, 시간 기록은 유지합니다.
우선순위는 P1 파스텔 적색, P2 노란색, P3 파란색으로 구분합니다. 리스트·칸반의 배지와 보고서 이미지에 같은 색을 사용하고, 칸반 카드 왼쪽 테두리에도 표시합니다.
카드의 상태 드롭다운은 표시하지 않습니다. 터치·키보드에서는 수정 버튼으로 상태를 바꿀 수 있습니다. 카드에는 오늘 기록한 소요시간을 표시하며, 이동만으로 시간을 추가하지 않습니다.
분류 필터는 두 보기와 오늘 업무 기록·시간 합계에 함께 적용됩니다. 보기와 필터 선택은 새로고침하면 초기화됩니다.
출퇴근·휴게는 날짜와 24시간 시각을 나누어 입력합니다. 시각은 `09:00` 또는 `0900`으로 입력하며 `00:00`~`23:59`만 허용합니다.
수동 근무 입력은 겹친 기존 세션 전체보다 우선합니다. 저장 전 대체할 기록 수를 안내하고 원본은 근무의 변경 이력에 보관합니다.
변경 이력에서 기존 기록을 다시 불러와 수동으로 저장할 수 있으며, 합계에는 현재 유효한 기록만 반영합니다.
새 수동 근무의 기본 휴게는 12:00~13:00입니다. 직접 수정하지 않은 기본 휴게는 출근 날짜를 따라가며 기존 기록의 휴게 값은 보존합니다.
휴게가 출퇴근 경계에 걸쳐도 저장할 수 있으며 실제 근무와 겹치는 시간만 차감합니다.
자동 목록 갱신은 60초 간격이며 외부 배송 서비스를 조회하는 동작은 아닙니다.

## 보고 이미지

이미지 아래의 텍스트 보고 메시지는 `26.11.2 진행 업무 보고드립니다.`와 번호별 업무명, 들여쓴 `- 세부내용` 형식입니다. 선택한 보고 날짜의 일일 진행사항만 포함하며 진행 예정사항·공유사항·시간·우선순위는 포함하지 않습니다. 편집 시 즉시 갱신되고 **메시지 복사**로 복사할 수 있습니다. 세부내용은 줄마다 항목으로 표시하며, 세부내용이 없는 업무는 제목만 표시합니다. 진행사항이 없으면 빈 메시지를 표시하고 복사 버튼을 비활성화합니다.

진행사항·결과·상태·소요시간, 예정사항·우선순위(P1~P3)·예상 소요시간·진행도를 표로 표시합니다.
각 표는 최대 100행이며 너비 1200px, 긴 내용은 높이를 늘려 한 파일에 담습니다.
Canvas 높이 30000px 초과 시 오류를 표시하고 내용을 줄이도록 안내합니다.
PNG 다운로드와 미리보기는 같은 렌더러를 사용합니다.
워터마크는 우측 하단에 작은 회색 두 줄로 표시합니다.

## 원격 목업과 운영 경계

기존 [비공개 목업](https://whoiam-work-console.bonnyaphid2050.chatgpt.site)은 이전 가상 데이터 버전으로 유지합니다.
이번 기능은 로컬 서버용이며 실제 데이터·서버·보관함을 Sites에 배포하지 않습니다.
.openai/hosting.json은 기존 목업 식별 정보이며 운영 서버 배포 설정이 아닙니다.
저장소 전체를 복사·압축해 배포하지 않습니다.

이전 Node 진입점은 Python 메모리 데모를 실행하는 호환 명령으로 유지합니다.
`node apps/web/serve.mjs`도 Python 환경과 requirements.txt 설치가 필요합니다.

예상 소요시간은 `estimated_minutes`(미입력은 null, 0~525600 정수 분), 진행도는 `progress`(0~100 정수 %)로 저장합니다. 상태와 진행도는 독립적으로 입력하며 드래그나 시간 누적으로 자동 변경하지 않습니다. 업무 수정과 시간 기록에서 두 값을 갱신할 수 있습니다.
기존 ETA 값은 호환을 위해 저장소에 보존하되 새 UI에는 표시하지 않으며, 날짜를 소요시간으로 추정 변환하지 않습니다. 기존 업무의 예상시간은 미입력, 진행도는 완료 상태이면 100%, 그 외에는 0%로 표시합니다. 보고서에 추가되는 기본 진행도는 0%입니다.
