# WHOIAM Web Mockup

기능 구현 전 메뉴 구성과 화면 흐름을 검토하는 정적 목업입니다.
모든 업무·물품·시간·보고 내용은 가상 데이터이며 로그인·API·DB·외부 서비스·영구 저장을 사용하지 않습니다.
화면에서 체크하거나 출근을 선택한 결과는 메모리에만 반영되며 새로고침하면 초기화됩니다.

## 메뉴

| 메뉴 | 화면 |
| --- | --- |
| 홈 | 출퇴근 진입, 할 일, 근무 요약, 확인할 항목, 빠른 명령 |
| 업무 | 오늘 할 일, 진행·완료, 다음 예정사항 |
| 물품 | 구매·배송·증빙 / 재고·보관 위치·BOM 소모 예시 |
| 기록 | 근무시간 / 진행사항·소요시간과 예정사항·우선순위·ETA를 담는 한 장 보고 이미지 |
| 설정 | 근무 기준·시간대·장치·민감정보 보관함의 구성 |

큰 화면은 왼쪽 메뉴, 작은 화면은 하단의 같은 5개 메뉴를 사용합니다.
우측 상단 기기 아이콘은 작은 화면 레이아웃으로 전환합니다.
이는 MCU용 웹 인터페이스를 염두에 둔 구성 검토이며 특정 MCU의 메모리·성능에서 검증한 펌웨어는 아닙니다.

## 로컬 실행

```powershell
node apps/web/serve.mjs
```

`http://127.0.0.1:4173`에서 확인합니다. 서버는 정해진 정적 자산만 제공하며 저장소나 `.private/`에 접근하지 않습니다.
추가 패키지 설치·프레임워크·빌드 과정이 필요하지 않습니다. 배포 정적 자산은 `index.html`, `styles.css`, `app.js`, `report.css`, `report.js`, `favicon.svg`입니다.
`serve.mjs`와 이 README는 배포 산출물에 포함하지 않습니다.

## 한 장 일일 업무보고

`기록 → 일일 보고`에서 진행사항과 소요시간(정수 분), 예정사항과 우선순위(P1~P3)·ETA(예상 완료 시각)를 직접 편집합니다.
각 표는 최대 6개 행을 지원합니다. 소요시간 미입력과 ETA 미정도 표시하며 예정사항은 우선순위·ETA 순으로 정리합니다.
한 장 미리보기와 PNG 저장은 같은 Canvas 렌더러를 사용합니다. 너비는 1200px이며, 긴 내용은 이미지 높이를 늘려 잘림 없이 한 파일에 담습니다.
우측 하단 워터마크는 `오동걸 업무비서 whoiam`과 `버전 0.01 · powered by codex`를 작은 회색 두 줄로 표시하며 PNG 픽셀에 포함됩니다.
입력은 브라우저 메모리에서만 유지하며 서버로 보내거나 브라우저 저장소에 영구 보관하지 않습니다. 새로고침하면 가상 예제로 초기화됩니다.
