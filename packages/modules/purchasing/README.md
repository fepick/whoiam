# Purchasing

주문·주문 항목·분할 배송·수령·반품·증빙 연결을 담당합니다.
사용자가 알아보는 이름·용도·프로젝트·제조사 품번·판매처 상품명과 메모를 관리합니다.
주문 자체는 재고를 증가시키지 않으며 실제 수령 수량을 재고 모듈에 전달합니다.
로그인·결제·개인정보는 민감정보 모듈의 참조 ID로 연결합니다. 현재 증빙 원본은 `.private/database/` 안의 암호화 레코드로 관리합니다.

## 구현

주문은 판매처·주문번호·용도 메모·프로젝트·금액·도착 예정일·여러 주문 품목을 수동 등록합니다.
발주만으로 재고가 늘지 않습니다. 분할 수령 시 남은 수량을 검사하고 포장당 재고 단위 수량으로 환산합니다.
수령과 재고 입고는 같은 트랜잭션에서 처리해 둘 중 하나만 기록되는 상태를 방지합니다.
배송 예정일과 주문·배송 상태를 갱신하며 거래명세서·카드매출전표를 민감정보 모듈의 검증된 참조로 연결합니다.
증빙 파일은 별도 평문 파일 대신 `.private/database/` 안에 암호화해 저장합니다.
판매처 자동 구매·실시간 배송 조회·반품 처리는 아직 제공하지 않습니다. 화면의 등록은 실제 결제를 실행하지 않습니다.
