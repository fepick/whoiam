# Tasks

할 일·예정일·우선순위·진행 상태·업무 로그를 관리합니다.
출근 시 이전 미완료와 당일 예정 업무를 제공하고, 퇴근 시 실제 기록과 비교할 근거를 제공합니다.
기록 부재를 미완료로 단정하지 않습니다. 실제 업무 내용은 로컬 운영 DB에 둡니다.

## 구현

`Tasks.save`로 업무 제목·메모·분류·우선순위(P1~P3)·예정일·ETA·상태를 등록·수정합니다.
`log`는 날짜별 소요시간(정수 분)과 결과를 누적하고 `update_log`로 정정합니다.
완료 체크만으로 소요시간을 만들어내지 않습니다. 로그가 없는 업무는 보고서에 완료 기록으로 넣지 않습니다.
`today`는 당일까지 예정된 미완료 업무, `daily`는 해당 날짜에 실제 입력한 로그를 반환합니다.
과거 업무 근거를 보존하기 위해 삭제 대신 `archived` 상태를 사용합니다.
