# Attendance

근무 세션·출퇴근·휴게·수정 이력·주간 합계·급여 대조를 담당합니다.
회사 규칙과 시간대를 설정으로 분리하고, 기록 누락 시 계산을 미확정으로 표시합니다.
원본 근무·급여 자료는 로컬에서만 관리하고 사용자 정보는 민감정보 모듈의 참조 ID로 연결합니다.

## 구현

출근·휴게 시작·휴게 종료·퇴근 이벤트와 수동 기록·사유를 남기는 정정을 지원합니다.
겹치는 세션·휴게 구간을 거부하고, 휴게 중 퇴근하면 해당 휴게를 닫습니다. 휴게는 자동으로 추정해 빼지 않습니다.
UTC 시각을 저장하고 Asia/Seoul의 월요일~일요일 경계로 구간을 나눠 주간 합계를 구합니다.
주 경계를 넘는 야간 근무와 휴게도 실제 겹치는 구간만 반영합니다. 초를 합산한 뒤 분으로 내림합니다.
진행 중인 세션은 잠정 합계이며 24시간 이상 종료하지 않은 기록은 누락 확인 대상으로 표시합니다.
기본 52시간은 사용자 알림 기준이고 설정으로 변경할 수 있습니다. 법적 근로시간·수당 판정을 자동화하지 않습니다.
급여는 월별 예상 실수령액과 실제 입금액(정수 원)을 직접 입력해 차이를 대조합니다.
세율·수당·회사 급여 규정이 없어 법정 수당이나 세후 급여를 추정하지 않습니다.
