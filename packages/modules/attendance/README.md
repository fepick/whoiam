# Attendance

근무 세션·출퇴근·휴게·수정 이력·주간 합계·급여 대조를 담당합니다.
회사 규칙과 시간대를 설정으로 분리하고, 기록 누락 시 계산을 미확정으로 표시합니다.
원본 근무·급여 자료는 로컬에서만 관리하고 사용자 정보는 민감정보 모듈의 참조 ID로 연결합니다.

## 구현

출근·휴게 시작·휴게 종료·퇴근 이벤트와 수동 기록·사유를 남기는 정정을 지원합니다.
휴게 구간의 중복은 거부하고, 휴게 중 퇴근하면 해당 휴게를 닫습니다. 휴게는 자동으로 추정해 빼지 않습니다.
UTC 시각을 저장하고 Asia/Seoul의 월요일~일요일 경계로 구간을 나눠 주간 합계를 구합니다.
주 경계를 넘는 야간 근무와 휴게도 실제 겹치는 구간만 반영합니다. 초를 합산한 뒤 분으로 내림합니다.
진행 중인 세션은 잠정 합계이며 24시간 이상 종료하지 않은 기록은 누락 확인 대상으로 표시합니다.
기본 52시간은 사용자 알림 기준이고 설정으로 변경할 수 있습니다. 법적 근로시간·수당 판정을 자동화하지 않습니다.
급여는 월별 예상 실수령액과 실제 입금액(정수 원)을 직접 입력해 차이를 대조합니다.
세율·수당·회사 급여 규정이 없어 법정 수당이나 세후 급여를 추정하지 않습니다.

## 수동 시각 입력

수동 입력은 완료된 실제 근무 기록용입니다. 퇴근 예정 시각은 실제 근무 합계에 넣지 않습니다.
시계 오차는 5분까지 허용하며 그보다 미래인 종료 시각은 별도 메시지로 거부합니다.
종료 역순·7일 초과·미래 종료를 서로 다른 오류로 구분합니다. 자정을 넘긴 근무는 퇴근 날짜도 다음 날로 입력합니다.
브라우저의 오전/오후 표시와 관계없이 값은 24시간제의 한국 시각으로 전달하며, 화면에 입력한 값을 24시간제로 함께 표시합니다.

수동 입력은 겹치는 기존 근무 세션 전체보다 우선합니다. 겹친 기존 기록은 `superseded_by`로 연결해 보관하고 현재 목록·열린 세션·당일·주간 합계에서 제외합니다.
부분만 겹쳐도 기존 세션 전체를 대체하며 수동으로 입력한 시작·종료·휴게를 기준으로 계산합니다. 기존 휴게를 임의로 합치지 않습니다.
근무 중인 출근 기록과 이전 수동 기록도 같은 규칙을 적용합니다. 맞닿기만 하는 세션과 겹치지 않는 다른 날짜의 기록은 보존합니다.
한 번의 저장에서 기존 기록 보관과 수동 기록 저장은 하나의 트랜잭션으로 처리하며 실패하면 모두 취소합니다.
`history`는 대체된 기록과 정정 전 시각·휴게·사유를 제공합니다. 화면의 변경 이력에서 기존 기록을 새 수동 입력으로 불러올 수 있습니다.
