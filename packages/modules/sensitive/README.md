# Sensitive

로그인 정보·결제수단 참조·개인정보의 저장과 접근을 담당하는 로컬 보안 경계입니다.
이 디렉터리에는 공개 가능한 코드·문서·가상 테스트만 둡니다. 실제 값은 절대 넣지 않습니다.
로컬 암호화 저장·마스킹·잠금·목적별 접근 검사를 구현했습니다. 외부 판매처 자동 로그인 연동은 아직 없습니다.

## 책임

- 로컬 암호화 저장소와 OS 키 저장소 연결.
- 유형별 조회 권한, 잠금·해제, 참조 ID 발급, 마스킹.
- 외부 사이트 자동화에 필요한 값의 제한적 사용.
- 값이 없는 감사 기록, 자격증명 교체·삭제 및 백업·복원.
- 로그·AI 입력·일반 HTTP 응답·예외에서 비밀값 제거. 명시적인 로그인 일시 조회 응답은 예외입니다.

일반 모듈은 비밀값을 일괄 조회할 수 없습니다. 참조 ID 소지만으로 접근이 허용되지 않습니다.
프런트엔드에서 원문 목록을 조회하는 API는 제공하지 않습니다.

## 유형과 저장 경계

| 유형 | 내용 | 로컬 위치 |
| --- | --- | --- |
| credential | 로그인·API 자격증명 | `.private/database/`의 암호화 레코드 |
| payment-method | 카드 별칭·카드사·끝 네 자리·서비스 참조 | `.private/database/`의 암호화 레코드 |
| person | 이름·연락처·주소 등 필요한 개인정보 | `.private/database/`의 암호화 레코드 |
| session | 외부 사이트 쿠키·세션 | 현재 미구현, 향후 `.private/sessions/` |
| document | 구매 증빙·급여 자료 | `.private/database/`의 암호화 레코드 |

전체 카드번호는 기본 저장 범위에서 제외하고 CVC/CVV·PIN·트랙 데이터는 저장하지 않습니다.
키는 위 위치에 보관하지 않고 OS 보안 저장소와 연결합니다.

## 현재 구현

`Sensitive.save/list/remove`는 유형별 허용 필드를 검사하고 목록에 별칭·유형·마스킹만 반환합니다.
전체 카드번호·CVC·PIN 등 허용하지 않은 필드는 저장하지 않습니다. 자격증명 비밀번호의 공백은 원문대로 유지합니다.
`use`는 연동 주체·목적별 허용 목록을 검사하며 현재 허용된 외부 연동은 없어 원문 사용을 전부 거부합니다.
`reveal`은 잠금 해제된 저장소에서 `local-ui`의 `credential-view` 목적에만 로그인 한 건의 ID·비밀번호를 반환합니다. 결제수단·개인정보는 거부합니다.
인증된 로컬 세션의 `POST /api/vault/reveal`에서만 호출하며 CSRF·Origin 검사를 거칩니다. 일반 코어 명령·스냅샷·재시도 결과 캐시에는 원문을 넣지 않습니다. 응답은 `Cache-Control: no-store`입니다.
웹의 설정 → 보관함 목록 → 로그인 정보의 **보기**를 누르면 최대 30초간 표시합니다. 지금 숨기기·닫기·Esc·화면 이동·다른 창/탭 이동·페이지 이탈·잠금 확인 시 원문 DOM을 제거합니다. 조회 중 닫은 경우 늦은 응답도 표시하지 않습니다.
원문은 영구 브라우저 저장소나 클립보드에 자동 저장하지 않습니다. 이는 UI에서 노출을 제한하는 기능이며 사용자가 직접 복사한 내용이나 캡처를 회수하지는 않습니다.
모든 레코드와 증빙 원문은 platform의 인증 암호화 저장소를 사용합니다. 키는 OS 보안 저장소에 분리합니다.
PDF·PNG·JPEG 증빙은 5MB까지 저장하며 유형 검사 후 불투명 참조 ID로 연결합니다.
다운로드는 인증된 로컬 세션에서만 허용하며 브라우저의 미리보기 실행 대신 첨부 파일로 반환합니다.
감사 기록은 작업명·참조 ID·시각만 저장합니다. 요청 본문·원문·파일명은 감사 기록에 남기지 않습니다.

가상 데이터로 마스킹·원문 접근 거부·잠금·증빙 유형·암호문 검증을 테스트합니다.
실제 OS 키 저장소 접근은 개발 도구로 실행하지 않습니다. 현재 사용자 계정에서 초기 실행 시 백엔드 지원 여부를 확인합니다.
인증 암호화 백업과 복원 전 안전 백업, 별도 암호 기반 복구 파일을 platform에서 제공합니다.
운영·개발·테스트 저장소의 OS 키는 UUID와 프로필로 분리합니다. [운영 절차](../../../docs/personal-service.md)를 따릅니다.
암호화 키 교체와 외부 판매처별 원문 사용 권한은 미구현 항목으로 남습니다.

## 향후 확장 경계

- `domain/`: 데이터 유형·접근 정책·참조 ID.
- `application/`: 등록·교체·삭제·마스킹·목적별 사용.
- `ports/`: 암호화·키 저장소·저장·감사 인터페이스.
- `adapters/`: 선택한 기술 스택의 로컬 구현.
- `tests/`: 권한·잠금·마스킹·변조 검출·복원 검증. 가상 데이터만 사용.

직렬화 가능한 일반 DTO에 비밀번호·카드 원문을 포함하지 않습니다. 사용자 요청에 따른 로그인 일시 조회의 전용 응답만 예외입니다.
허용된 로컬 연동에 짧은 범위로 제공하고 비밀값을 코어·이벤트·보고서로 반환하지 않습니다.
세부 동작과 위협 모델은 구현 전에 확정합니다.
