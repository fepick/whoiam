# Reporting

## 실제 기록 연결

`Reporting.generate`는 날짜별 업무 로그를 업무 단위로 합산하고 미완료 업무의 우선순위·예상시간·진행도로 예정사항을 구성합니다.
근무시간과 수동 입력 소요시간은 별도로 저장합니다. 로그가 없는 일을 완료했다고 만들지 않습니다.
초안은 수동으로 수정해 암호화 저장할 수 있습니다. 같은 날짜의 초안을 다시 생성하면 수동 편집 내용을 대체하므로 화면에서 확인합니다.
각 표는 최대 100개 업무이며, PNG 렌더러는 긴 내용에 맞춰 높이를 늘립니다. 브라우저 Canvas 한도를 넘는 경우 오류를 표시합니다.
초안 생성 시 100개를 넘는 업무와 2000자를 넘는 상세 기록은 표시 범위를 공유사항에 명시하고 원본 업무 로그를 보존합니다.
보고 내용이 많다는 이유로 퇴근 기록이 실패하지 않도록 생성 표의 범위를 제한합니다.
PNG는 브라우저에서 로컬 생성·다운로드하며 외부 이미지 생성 서비스를 사용하지 않습니다.

업무 로그와 모듈 기록을 바탕으로 오늘 한 일·진행 중인 일·문제점·다음 예정사항의 초안을 만듭니다.
사용자가 수정할 수 있으며 원본 근거와 연결합니다. 생성과 외부 제출은 별개 명령입니다.
보고서 원본은 로컬 운영 데이터입니다. AI 입력은 로컬에서 개인정보를 제거·가명화하고 필요한 범위로 제한합니다.

## 이미지 출력 형식

웹은 PNG 아래에 일일 진행사항만 번호별 업무명과 세부내용으로 정리한 텍스트 보고 메시지도 제공합니다. 선택한 보고 날짜를 `YY.M.D`로 표시하고 진행 예정사항은 제외합니다. 보고 편집 내용에서 즉시 생성하며 메시지 복사 버튼을 제공합니다. 텍스트는 별도 저장하지 않고 기존 보고서의 일일 진행사항에서 다시 만듭니다.

- 일일 진행사항: 업무·결과, 진행 상태, 직접 입력 가능한 소요시간(분), 합계.
- 진행 예정사항: 업무·다음 행동, 우선순위(P1~P3), 예상 소요시간(분)과 진행도(%).
- 공유·확인사항과 보고 날짜.
- 우측 하단 워터마크: `오동걸 업무비서 whoiam` / `버전 0.03 · powered by codex`. 작은 회색 두 줄로 우측 정렬합니다.

현재 `apps/web/report.js`는 로컬 서버에서 불러온 보고서와 편집 내용을 Canvas로 그려 한 장 PNG를 만듭니다.
이미지 너비는 1200px이며 긴 내용은 높이를 늘려 보존합니다. 원본 저장은 로컬 API에 명시적으로 요청하며 외부 서버·AI로 전송하지 않습니다.
업무별 소요시간 합계는 입력한 값의 합이며 출퇴근 기록으로 계산한 근무시간과 구분합니다.

예상 소요시간은 `estimated_minutes`(미입력은 null, 0~525600 정수 분), 진행도는 `progress`(0~100 정수 %)로 저장합니다. 상태와 진행도는 독립적으로 입력하며 드래그나 시간 누적으로 자동 변경하지 않습니다. 업무 수정과 시간 기록에서 두 값을 갱신할 수 있습니다.
기존 ETA 값은 호환을 위해 저장소에 보존하되 새 UI에는 표시하지 않으며, 날짜를 소요시간으로 추정 변환하지 않습니다. 기존 업무의 예상시간은 미입력, 진행도는 완료 상태이면 100%, 그 외에는 0%로 표시합니다. 보고서에 추가되는 기본 진행도는 0%입니다.
