# Reporting

업무 로그와 모듈 기록을 바탕으로 오늘 한 일·진행 중인 일·문제점·다음 예정사항의 초안을 만듭니다.
사용자가 수정할 수 있으며 원본 근거와 연결합니다. 생성과 외부 제출은 별개 명령입니다.
보고서 원본은 로컬 운영 데이터입니다. AI 입력은 로컬에서 개인정보를 제거·가명화하고 필요한 범위로 제한합니다.

## 이미지 출력 형식

- 일일 진행사항: 업무·결과, 진행 상태, 직접 입력 가능한 소요시간(분), 합계.
- 진행 예정사항: 업무·다음 행동, 우선순위(P1~P3), ETA(예상 완료 날짜·시각).
- 공유·확인사항과 보고 날짜.
- 우측 하단 워터마크: `업무비서 whoiam` / `버전 0.01 · powered by codex`. 작은 회색 두 줄로 우측 정렬합니다.

현재 `apps/web/report.js`는 가상 예제와 브라우저 메모리상의 편집 내용을 Canvas로 그려 한 장 PNG를 만듭니다.
이미지 너비는 1200px이며 긴 내용은 높이를 늘려 보존합니다. 서버·AI 전송이나 원본 영구 저장은 수행하지 않습니다.
업무별 소요시간 합계는 입력한 값의 합이며 출퇴근 기록으로 계산한 근무시간과 구분합니다.
