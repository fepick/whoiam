# Inventory

입고·사용·폐기·반품·실사 조정 이력을 기준으로 수량을 관리합니다.
BOM 버전·조립 수량·대체품·추가 손실·실제 소모를 기록하며 과거 작업의 BOM은 유지합니다.
구매 단위와 재고 단위를 구분합니다. 운영 DB는 `.private/database/`에 둡니다.

## 구현

`Inventory`는 품목·정수 수량의 입출고 원장·실사 조정·BOM·조립 이력을 제공합니다.
잔량은 원장 합계로 계산하며 음수 재고를 허용하지 않습니다. 원장에는 사유와 관련 작업 ID가 남습니다.
품목의 단위에 맞춘 수량을 입력하며 구매 포장 단위 환산은 수령 시 명시적으로 지정합니다.
같은 이름과 버전의 BOM은 덮어쓰지 않습니다. 변경하려면 새 버전을 등록합니다.
조립 미리보기는 보드 수 × 보드당 수량 + 소자별 추가 손실을 계산합니다.
하나라도 부족하면 아무 소자도 차감하지 않으며, 성공하면 당시 BOM과 소모량을 조립 이력에 저장합니다.
대체품 자동 선택·소수 단위 재고는 아직 제공하지 않습니다.
