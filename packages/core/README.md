# Core

명령 등록·라우팅, 출근·퇴근 흐름, 예약 작업, 실행 이력 및 중복 방지를 담당합니다.
업무 규칙은 해당 모듈에 위임합니다. 민감정보는 참조 ID로만 전달하며 원문을 로그나 AI 입력으로 전달하지 않습니다.
`Core.execute`가 공개 모듈 명령을 라우팅하고 요청 UUID와 입력 지문을 암호화 저장해 재시도를 중복 적용하지 않습니다.
같은 요청 ID에 다른 명령이 들어오면 거부합니다. 여러 모듈의 변경은 하나의 DB 트랜잭션으로 처리합니다.

출근은 실제 시각 기록·당일 미완료 업무·도착 예정 주문·증빙·부족 재고를 연결합니다.
퇴근은 근무 종료·주간 합계·놓친 항목·실제 업무 로그 기반 보고 초안 생성을 함께 처리합니다.
자연어 입력은 출근·퇴근·휴게 시작·휴게 종료·오늘 할 일·재고·배송·보고 등 명시된 명령으로 한정합니다.
부분 문자열로 명령을 추정하지 않고 외부 AI로 업무 내용을 보내지 않습니다.
예약 배송 조회와 판매처 자동화는 아직 없으며 화면을 열면 현재 날짜와 기록에 따라 확인 목록을 갱신합니다.
